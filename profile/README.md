# Tiny Robot Lab 🤖

I build things to understand how they work.

Tiny Robot Lab is an open learning project where I explore AI agents, autonomous systems, and related technologies by building them, testing them, documenting the architecture, and sharing what I learn.

## Current Lab

### Tiny Agent Lab

Tiny Agent Lab explores autonomous-agent patterns through a working generic prototype.

- **Live Lab:** https://agents.tinyrobotlab.com
- **Source:** https://github.com/Tiny-Robot-Lab/autonomous-agent-lab
- **Roadmap:** https://tinyrobotlab.com/roadmap.html

The project is open for learning, and the architecture, tests, experiments, tradeoffs, and known boundaries are deliberately kept visible.

## Build · Learn · Share

The goal isn't to pretend experimental software is production-ready. It's to build enough to understand how the pieces work, test the assumptions, learn from what breaks, and share the useful parts along the way.
